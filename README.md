# ShopCart - Full Stack E-Commerce App

## Project Structure
- `client/vite-project`: Frontend built with React, Vite, and Tailwind/CSS.
- `server`: Backend built with Node.js, Express, and Database.

## Setup & Installation

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/your-username/ShopCart.git
cd ShopCart
\`\`\`

### 2. Run the Server
\`\`\`bash
cd server
npm install
# Create a .env file and add your environment variables
npm run dev
\`\`\`

### 3. Run the Client
\`\`\`bash
cd client/vite-project
npm install
npm run dev
\`\`\`
